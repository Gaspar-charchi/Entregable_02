# INS-TEC — Proyecto final Frontend Developer Web

## Contenido
- `index.html`: estructura semántica de la página.
- `css/estilos.css`: diseño visual, responsive, Flexbox y CSS Grid.
- `js/script.js`: validaciones, eventos DOM y simulación de formulario.
- `img/`: carpeta disponible para imágenes locales.

## Cómo ejecutar
1. Descomprime la carpeta.
2. Abre `index.html` en un navegador moderno. También puedes abrir la carpeta en Visual Studio Code y usar la extensión Live Server.
3. Necesitas conexión a Internet para cargar Bootstrap y las imágenes remotas.

## Tecnologías demostradas
- HTML5: `header`, `nav`, `main`, `section`, `article`, `form`, `fieldset`, `legend` y `footer`.
- CSS3: variables CSS, media queries, Flexbox, Grid, estados de interacción y preferencia de movimiento reducido.
- Bootstrap 5: contenedores, grillas, botones, tarjetas, formulario y menú adaptable.
- JavaScript: constantes, objetos, funciones, condiciones, ciclos, eventos, manipulación del DOM, `FormData`, expresiones regulares y `async/await`.

## Importante sobre el formulario
El envío es una simulación didáctica. Los datos se muestran en la consola y se presenta una confirmación, pero no se envían a un servidor ni se guardan en una base de datos. No uses datos personales reales en una demostración pública.

## Antes de entregar
- Verifica los nombres de archivos y rutas.
- Sustituye los datos ficticios de contacto por los autorizados por el docente.
- Confirma con el docente las carreras y duraciones: en este prototipo son referenciales.
- Prueba el menú y el formulario en escritorio y móvil.
- Añade capturas de pantalla y explica las pruebas en el informe técnico.
